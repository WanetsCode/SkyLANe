note: skyLANe is a little tool intended for quick LAN contributions and plays, it is different to the official multiplayer feature. Since its small its intended for parties for up to 5 people (can be exceeded) and therefore donesnt contain features like protection zones, everybody can do everything in your city if you allow them. Banning and kicking are not implemented since you can just ban them from the hotspot

---

## Setup:

follow the guests guide if you want to join a friend's server, follow host guide if you want to make your own servers to host

### For Guests:

1. Go to the releases tab (on the right)
2. Find the latest release that has your version
3. Download the plugin (skylane.ttplugin or skylane.zip depending on version and client)
4. Follow [this guide](https://pca.svetikas.lt/docs/getting-started/installing/) to install the plugin in theotown
5. Reopen the game and above your account icon press the new "SkyLANe" button and configure some basic stuff

you can now join servers! (scroll down to see how)

### For Hosts:

1. Go to the releases tab (on the right)
2. Find the latest release that has your version
3. Download the plugin (skylane.ttplugin or skylane.zip depending on version and client)
4. Download the host app (clientapp.apk, clientapp.exe depending on the device (see tags) )
5. Open the app and make sure it says "TheoTown detected!" (if it says "No TheoTown your version is probably pirated or old")
6. Follow [this guide](https://pca.svetikas.lt/docs/getting-started/installing/) to install the plugin in theotown
7. Reopen the game and above your account icon press the new "SkyLANe" button and configure some basic stuff, check the "i am a host" checkbox
8. Open the app again, it should show "Connected to plugin"

you can now host servers! (scroll down to see how)
